Built for production
Every request inspected.
In milliseconds.

ShieldGate middleware runs inside your app — checking Redis for blacklists and rate counters before your endpoint ever sees the request.

Rate limiting engine
Atomic Redis counters — blocks happen in under 1ms, before your view function runs. Per key, per IP, or both.
Brute force detection
Counts failed logins per IP. Automatic lockout after your threshold. Duration fully configurable.
Full audit logging
Every request recorded — method, path, IP, status, latency. Searchable, exportable, retained up to a year.
IP blacklisting
Manual and automatic blocking, propagated across every request in under a second via Redis.
Per-endpoint rate limitsNEW
Set different limits per route — stricter on /login, looser on /search — instead of one blanket limit per key.
AI traffic awarenessNEW
Tags requests hitting known LLM/AI patterns and applies a separate rate-limit tier, without a second product to configure.
API key management
Generate, rotate, and revoke keys with full lifecycle control. Keys are stored hashed — never in plain text.
Alert system
Email and webhook alerts when threat score or usage/spend exceeds a threshold you set, with cooldowns.

FAQ
Questions developers actually ask us.
Does the free plan actually protect production traffic?

Yes — the free tier includes rate limiting, IP blacklisting, brute force detection, and audit logs, just at lower limits (500 requests/day, 1 API key, 7-day log retention). It's not a crippled trial, it's a smaller version of the real thing.

Do you support Naira billing?

Yes. Nigerian customers pay via Paystack — card, bank transfer, or USSD. International customers pay via Stripe. Naira pricing is reviewed quarterly against the exchange rate.

What happens to my data if I cancel?

Your audit logs remain accessible for 30 days after cancellation so you can export them, then they're deleted. API keys are deactivated immediately.

Do I need a Go or PHP SDK to use ShieldGate?

No — the REST API covers every language with no SDK required. A dedicated Go SDK is on the roadmap as a fast-follow after launch.
